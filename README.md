# Body Harmony

A responsive BMI and wellness tracking web application built with HTML, CSS, and JavaScript.

## Overview

Body Harmony is an interactive wellness application that allows users to calculate and track their Body Mass Index (BMI) while exploring additional wellness information.

The application combines a simple BMI calculator with an interactive interface designed to make health-related data easier to understand.

## Features

- BMI calculation
- Height and weight unit selection
- Gender selection
- BMI classification and visual scale
- Wellness recommendations
- Light and dark themes
- Voice input
- BMI history tracking
- BMI history chart
- Local browser storage
- Shareable results
- Responsive design
- Interactive user interface

## Technologies

- HTML5
- CSS3
- JavaScript
- HTML Canvas
- Web Speech API
- Browser Local Storage
- Chart.js

## How It Works

Users enter their height and weight using the available unit options.

The application calculates BMI and presents the result using a visual classification scale.

Previous results can be stored locally in the browser and displayed as a history chart, allowing users to observe changes over time.

## Privacy

BMI history is stored locally in the user's browser using local storage.

No backend or database is required for the application.

## Running Locally

Download or clone the repository and open `index.html` in a modern web browser.

No backend is required.

## Project Purpose

This project explores how interactive web interfaces can present numerical wellness information in a simple and understandable way.

The focus was on responsive interface design, user interaction, data visualization, and client-side JavaScript functionality.

## Important Note

This application is intended for educational and informational purposes.

BMI is a general screening measure and does not provide a complete assessment of an individual's health or fitness.
